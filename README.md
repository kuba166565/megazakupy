# MegaZakupy.pl

**MegaZakupy.pl** to prosty sklep internetowy zbudowany w React i Tailwind CSS.

## Demo

Możesz uruchomić projekt lokalnie lub wdrożyć go przez [Vercel](https://vercel.com) lub GitHub Pages.

## Jak uruchomić lokalnie

1. Sklonuj repozytorium:
   ```bash
   git clone https://github.com/TWOJA-NAZWA-UZYTKOWNIKA/megazakupy.git
   cd megazakupy
   ```

2. Zainstaluj zależności:
   ```bash
   npm install
   ```

3. Uruchom projekt:
   ```bash
   npm start
   ```

Projekt zostanie uruchomiony pod `http://localhost:3000`.

## Technologie

- [React](https://reactjs.org)
- [Tailwind CSS](https://tailwindcss.com)
- [Vite](https://vitejs.dev) (opcjonalnie)
